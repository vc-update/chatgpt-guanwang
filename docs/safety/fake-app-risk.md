# ChatGPT 假 App 常见套路

<div class="quick-answer">
  <strong>直接结论：</strong>下载 ChatGPT App 时，先从 `chatgpt.com/download` 或系统应用商店核对开发者信息。不要只凭图标、名称和“中文版”“官方版”字样判断真假。
</div>

<div class="recommend-box">
  <strong>国内可用方案：</strong>官方 App 入口仍以 <code>chatgpt.com</code> 和官方应用商店为准。如果你暂时不方便安装官方 App，又想在手机上体验接近官网的聊天和多模型能力，可以了解 <a href="https://gptcat.cc/" target="_blank" rel="noreferrer">GPTCat</a>；它更适合作为国内练习环境，而不是官方 App 替代声明。
</div>

## 假 App 常见套路

| 套路 | 表现 | 应对方式 |
| --- | --- | --- |
| 相似图标 | 图标和 ChatGPT 很像 | 核对开发者和下载来源 |
| 标题堆词 | 写“ChatGPT 中文版”“官方 AI” | 不看标题，先看开发者 |
| 诱导登录 | 要求输入 OpenAI 账号 | 确认是否为官方登录流程 |
| 过度权限 | 请求通讯录、短信、悬浮窗 | 非必要权限直接拒绝 |
| 不明安装包 | 通过网盘、群文件传播 | 不安装来源不明 APK |

## 下载前核对清单

1. 先打开 `chatgpt.com/download`。
2. 根据页面提示进入官方应用商店。
3. 核对开发者名称、应用详情页、评价异常和更新时间。
4. 安装后检查是否要求不合理权限。
5. 登录前再次核对页面来源。

## Windows 桌面版也要核对

Bing 搜索中“ChatGPT 下载”“ChatGPT 桌面版”会出现 Microsoft Store、官方介绍页，也会出现第三方教程和下载站。桌面端尤其要避免从网盘、论坛附件或不明压缩包安装。

## FAQ

### 应用商店里所有 ChatGPT 名称的 App 都是官方的吗？

不是。应用商店里可能有第三方 AI 工具、教程类 App 或仿冒应用。下载前要看开发者和详情页来源。

### 假 App 会造成什么后果？

轻则广告和诱导订阅，重则泄露账号、验证码、聊天内容或设备信息。

### 不安装 App 可以用 ChatGPT 吗？

可以。网页版入口是 `chatgpt.com`，很多基础使用场景不一定需要安装 App。
