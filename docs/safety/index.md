## 安全核验顺序

先确认[ChatGPT 官方网址](/official/url)，再根据场景检查[仿冒网站](/safety/fake-site-checklist)、[假 App](/safety/fake-app-risk)或[镜像网站风险](/safety/mirror-risk)。任何第三方平台都不应被视为 OpenAI 官方中文版，输入账号、付款或上传文件前应单独核对其隐私和服务条款。
