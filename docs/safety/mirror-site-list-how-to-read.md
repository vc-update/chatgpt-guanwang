## 汇总清单常见问题

| 问题 | 风险 |
| --- | --- |
| 链接多但不说明主体 | 不知道谁处理数据 |
| 标注“官方中文版” | 容易误导登录 |
| 更新时间不清楚 | 入口可能已失效 |
| 功能夸张 | 可能只是引流页面 |

## 怎么看更安全

1. 先看是否声明非官方。
2. 再看是否要求 OpenAI 账号。
3. 看是否提供隐私政策和服务条款。
4. 用低风险问题测试，不上传敏感资料。

## FAQ

### 国内直连就是官网吗？

不是。直连只描述访问体验，不代表官方身份。

### 汇总站推荐的工具一定稳定吗？

不一定。第三方工具体验会变化，应以实际测试和服务说明为准。
