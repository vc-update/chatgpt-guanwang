# ChatGPT 钓鱼链接怎么识别

<div class="quick-answer">
  <strong>直接结论：</strong>识别 ChatGPT 钓鱼链接，核心看最终域名、跳转链路、登录页面来源和是否索要敏感信息。标题写“官方入口”不等于真的官方。
</div>

<div class="recommend-box">
  <strong>国内可用方案：</strong>官方入口仍以 <code>chatgpt.com</code> 和 <code>openai.com</code> 为准。如果你需要国内可访问的练习环境，可以在明确第三方属性的前提下了解 <a href="https://gptcat.cc/" target="_blank" rel="noreferrer">GPTCat</a> 或 <a href="https://snakegpt.vip/" target="_blank" rel="noreferrer">SnakeGPT</a>，并使用独立账号与密码。
</div>

## 钓鱼链接常见来源

| 来源 | 常见话术 | 风险 |
| --- | --- | --- |
| 搜索广告 | 官方入口、免费版、中文版 | 可能诱导进仿冒页 |
| 群聊分享 | 最新可用入口、免登录 | 可能带短链和中转页 |
| 邮件通知 | 账号异常、立即验证 | 可能盗取验证码 |
| 下载站 | 官方安装包、破解版 | 可能夹带恶意文件 |

## 3 秒核对法

1. 鼠标悬停或长按查看真实链接。
2. 打开后看地址栏最终域名。
3. 如果不是 `chatgpt.com` 或 `openai.com`，不要输入官方账号。

## 高风险信号

1. 域名里塞入 `chatgpt`，但后缀和主体很陌生。
2. 页面要求先加客服或进群。
3. 登录页和官网很像，但浏览器地址栏不是官方域名。
4. 使用“永久免费”“必定可用”“官方合作”等绝对化话术。
5. 要求下载证书、插件、配置文件或远程控制软件。

## FAQ

### 搜索结果第一条一定安全吗？

不一定。搜索结果可能包含广告、第三方教程和非官方站点。官方入口仍要看域名。

### 朋友分享的链接可以直接登录吗？

不建议。朋友也可能转发了未核对的链接。登录前先检查最终域名。

### 钓鱼链接会只偷 ChatGPT 账号吗？

不一定。很多钓鱼页面真正想拿的是邮箱、支付信息、验证码或常用密码。
