## 最危险的四类操作

### 1. 把 API Key 填到陌生网站

API Key 可能产生费用，也可能暴露你的调用记录和账号风险。除非你完全理解该平台如何保存和使用 Key，否则不要填写。

### 2. 上传敏感图片

不要上传身份证、合同、后台截图、客户素材、未发布产品图、商业设计稿和真实人物照片。

### 3. 相信“永久免费无限生成”

图片生成有成本。所谓免费无限制可能通过排队、降质、收集数据、广告或隐藏付费实现。

### 4. 下载所谓 GPT-Image-2 客户端

图片生成通常不需要下载不明安装包。来源不明的 exe、dmg、apk 都要谨慎。

## 商业图片生成注意事项

1. 不要生成真实品牌 logo。
2. 不要模仿名人或公众人物。
3. 商品图要确认原图版权。
4. 广告素材要符合平台审核要求。
5. 生成图用于商业前要人工复核。

## 更稳的使用方式

1. 学习教程时只用无敏感素材。
2. 正式项目优先使用官方入口或可信服务端。
3. API Key 放自己服务器，不给第三方页面。
4. 对用户上传图片做脱敏和删除机制。
5. 重要商业图保留人工设计和审核。
