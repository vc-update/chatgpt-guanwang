# ChatGPT 下载站和安装包风险提醒

<div class="quick-answer">
  <strong>直接结论：</strong>下载站、网盘和论坛附件不是 ChatGPT 安装包的优先来源。能用网页版时，先用 <code>chatgpt.com</code>；必须安装时，再走官方下载页和应用商店。
</div>

<div class="recommend-box">
  <strong>国内可用方案：</strong>如果你只是想体验 AI 对话，不必为了下载客户端冒险安装不明包。可用浏览器访问官方入口，或了解 <a href="https://snakegpt.vip/" target="_blank" rel="noreferrer">SnakeGPT</a>、<a href="https://gptcat.cc/" target="_blank" rel="noreferrer">GPTCat</a> 这类第三方练习环境。
</div>

## 常见风险

| 安装包 | 风险 |
| --- | --- |
| exe | 被篡改、夹带程序 |
| dmg | 伪装官方客户端 |
| APK | 过度权限、仿冒应用 |
| 压缩包 | 附带脚本或未知文件 |

## 安全替代路径

1. 网页版优先用 `chatgpt.com`。
2. Windows 优先核对 Microsoft Store。
3. Android 优先核对 Google Play 或官方页面。
4. iOS 优先核对 App Store。

## FAQ

### 下载站写“官方版”可信吗？

标题不能证明来源。看最终下载来源、开发者和签名。

### 安装后才发现可疑怎么办？

断网卸载、修改相关密码、检查启动项和浏览器扩展，必要时做安全扫描。
