## 安装流程

1. 打开 `chatgpt.com/download`。
2. 选择适合系统的桌面版入口。
3. 跳转应用商店或官方页面后再下载。
4. 安装完成后核对登录页面来源。
5. 遇到下载失败，先排查系统和商店设置。

## FAQ

### 桌面版能替代官网入口吗？

不能。桌面版是客户端形式，账号和官方服务来源仍需核对。

### 安装后无法登录怎么办？

先确认客户端来源，再排查网络、账号、浏览器授权和官方服务状态。
