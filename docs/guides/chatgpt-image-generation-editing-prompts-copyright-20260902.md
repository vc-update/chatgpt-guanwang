## 1. ChatGPT 图片生成功能是什么

图片生成是让模型根据文字描述创建新图，也可以在支持编辑的界面中对已有图片进行局部修改。常见用途包括：

- 产品概念图、海报草稿和社交媒体配图
- 文章封面、头像和故事插图
- 电商场景图、背景替换和构图变化
- 对已有图片进行裁剪、重绘、换背景或调整风格

图片生成不是“输入一句话就得到最终成片”。清晰的需求、可控的素材、逐轮修改和人工核验，通常比追求一次成功更重要。

## 2. 从哪里进入官方图片功能

建议按以下顺序操作：

1. 手动输入 `https://chatgpt.com/`，确认地址栏域名和 HTTPS。
2. 登录后查看当前页面是否出现图片生成、创建图像或类似入口。
3. 如果功能入口不明显，先尝试在对话框描述“生成一张……”，再根据页面反馈判断账号是否支持。
4. 需要上传图片时，先确认上传按钮、文件类型、数据设置和当前账号的使用限制。
5. 下载前检查图片尺寸、文字、人物手指、商标和画面中是否出现不应有的内容。

## 3. 中文提示词怎么写：从一句话变成可执行描述

推荐使用下面的提示词顺序：

> 任务 + 主体 + 场景 + 构图 + 风格 + 光线/色彩 + 文字要求 + 尺寸比例 + 禁止项

例如，不要只写：

> 做一张咖啡海报

可以改成：

> 为一家城市独立咖啡店制作一张竖版海报。主体是一杯有拉花的拿铁，放在浅色木桌上，背景是窗边晨光和少量绿植，构图简洁、主体位于画面下方三分之一，整体为温暖的米白和咖啡色，留出顶部标题区域。海报只保留一个中文标题“今日手冲”，不要生成其他小字、品牌商标或水印，比例 4:5。

### 3.1 人物和场景模板

> 生成一张【人物身份】在【地点】完成【动作】的画面。镜头为【近景/半身/全身/俯拍】，主体位于【左/中/右】侧，使用【自然光/柔光/电影感光线】，色彩以【颜色】为主，画面比例为【比例】，不要出现【不需要的元素】。

### 3.2 产品图模板

> 生成【产品名称】的电商产品图。产品材质是【材质】，放在【背景/场景】中，采用【正面/45度/俯视】角度，光线为【光线】，突出【卖点】。画面干净、主体清晰，保留【留白位置】，比例【1:1/4:5/16:9】，不要虚构品牌 Logo、型号、认证标志或无法核实的参数。

### 3.3 中文海报文字模板

图片模型生成中文小字时可能出现错别字、乱码或不完整排版。更稳妥的做法是：

1. 先让模型生成无文字或只留文字区域的画面。
2. 下载后用设计软件补上标题、价格、日期和二维码。
3. 如果必须让模型生成文字，明确给出“只出现以下文字：……”，并逐字检查。

## 4. 图片编辑怎么做

编辑已有图片时，建议一次只改一个变量。比如先换背景，再调整服装颜色，最后处理画面比例。一次提出十几个修改要求，容易导致主体变形或细节丢失。

可以使用这样的编辑指令：

> 保留人物脸部、姿势和衣服不变，只把背景替换为浅灰色摄影棚；光线保持从左上方进入，不增加文字、Logo 或其他人物。

> 保留产品外形和材质，只将背景改成浅木色桌面，并在右侧留出约三分之一空白用于后期排版。

> 删除画面右下角的杂物，保持主体大小、视角、阴影方向和整体色调不变。

编辑后重点检查：人物身份是否被改变、产品细节是否被重绘、文字是否变形、背景边缘是否穿帮，以及是否误加入第三方商标或版权元素。

## 5. 生成失败或效果不理想怎么办

### 5.1 画面内容不对

把抽象形容词改成可观察的描述。例如把“高级、好看、科技感”改成“深色背景、冷白边缘光、低饱和蓝色、留白充足、产品位于右侧”。

### 5.2 中文文字乱码

减少图片中的文字，先生成排版底图，再在后期软件中加字。对于数字、价格、日期和专业名词，必须逐字核对。

### 5.3 人物或产品变形

降低一次修改的范围，明确“保留主体外形、姿势和视角不变”，并使用原图作为参考。连续编辑多轮后，建议与原图对照，避免细节逐步漂移。

### 5.4 页面没有图片入口

功能可能受账号、套餐、地区、模型或阶段性开放影响。先确认登录的是官方页面，再查看当前产品说明；不要因为没有入口就转向要求提交密码或 API Key 的陌生网站。

## 6. 隐私：哪些图片不建议直接上传

图片可能包含比文字更多的隐私和商业信息。以下内容不建议直接上传到普通网页或不透明的第三方平台：

- 身份证、护照、银行卡和人脸证件照
- 客户照片、未成年人照片和未公开的肖像素材
- 合同、报价单、后台截图、内部报表和员工信息
- 未发布的产品外观、设计稿、源文件和供应链资料
- 带有地址、电话、订单号、二维码或定位信息的截图

如果确实需要处理，先复制一份副本，删除姓名、号码、二维码和元数据，只保留完成任务所需的局部内容。更完整的上传前检查可参考站内文章：[ChatGPT上传文件安全吗：文档、图片、表格和隐私数据检查清单](../safety/chatgpt-upload-files-privacy-data-security-checklist-20260805)。

## 7. 版权和商用边界

“能生成”不等于“没有版权问题”。发布或商用前至少检查以下事项：

1. 提示词是否要求模仿在世艺术家、具体品牌或受保护角色。
2. 参考图是否获得了摄影师、客户或肖像权人的授权。
3. 画面中的 Logo、字体、包装、商标和产品外观是否可能造成混淆。
4. 人物是否为真实个人，是否需要肖像或商业使用许可。
5. 服务条款是否允许当前套餐和地区的商业使用。
6. 是否保留了原始素材、提示词、修改记录和人工审核记录。

对于广告、出版、商品包装和客户交付，建议把 AI 图片当作创意草稿或制作环节的一部分，由人工完成事实、品牌、文字和授权核验。涉及法律争议时，应咨询当地专业人士，不要只依赖一篇教程的结论。

- 当前可选模型和图片入口
- 每日或周期性额度提示
- 生成尺寸、下载格式和编辑限制
- 账号所在地区的功能开放情况
- 订阅、退款和自动续费说明

## 10. 一套可复用的安全工作流

可以把图片任务固定成下面 7 步：

1. 明确用途：草图、学习、社媒配图还是商业交付。
2. 选择入口：官方账号优先核对 `chatgpt.com`；第三方工具单独看服务主体。
3. 整理素材：只准备必要内容，先脱敏并保留原始副本。
4. 写第一版提示词：主体、场景、构图、风格、文字和比例写清楚。
5. 小步修改：每次只改一个主要变量。
6. 人工核验：检查文字、人物、品牌、商标、事实和授权。
7. 再发布或交付：保存提示词、版本和授权记录，方便后续追溯。

## 常见问题

### ChatGPT 图片生成是不是只能用英文提示词？

不是。中文提示词可以作为起点，关键是描述具体、结构清楚。遇到专有名词、尺寸或排版问题，可以把任务拆成“先生成画面、后期加字”两步。

### 可以上传网上找到的图片让 ChatGPT 改图吗？

先确认你拥有使用和修改该图片的权利。网上能看到不代表可以下载、改造或商用；人物、商标、摄影作品和插画尤其需要注意授权。

### 第三方平台的图片可以直接当作官方 ChatGPT 生成的吗？

不能这样表述。第三方平台可能调用不同模型或提供自己的工作流，服务主体、数据处理和计费规则与 OpenAI 官方不同。

### 为什么同一句提示词每次结果不一样？

生成模型具有随机性，且模型、参数、上下文和账号功能可能变化。重要交付应保留版本、提示词和人工筛选结果，不要只保存最终图片。
