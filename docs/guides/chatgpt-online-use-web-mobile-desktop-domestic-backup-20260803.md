## 官网打不开时怎么办

先排查官方网页版，不要马上去搜“国内唯一入口”：

| 现象 | 可能原因 | 处理建议 |
| --- | --- | --- |
| 页面白屏 | 缓存、扩展、脚本加载异常 | 换无痕窗口，清理站点 Cookie，关闭可疑扩展 |
| 登录后反复跳转 | Cookie、账号登录方式、设备切换 | 固定一种登录方式，减少频繁切换浏览器 |
| 提示网络或地区异常 | 网络环境、DNS、地区可用性 | 先确认官方域名，再排查本地网络 |
| 搜索结果很多入口 | 竞价广告、仿冒标题、聚合页 | 手动输入 `chatgpt.com` |
| 下载页诱导安装 | 假安装包或推广页 | 返回 `chatgpt.com/download` 或应用商店核对 |

如果你只是完成低风险任务，比如公开资料总结、中文润色、提纲生成，可以临时使用第三方工具。但涉及账号、合同、客户资料、密钥、内部代码时，建议暂停上传。

## FAQ

不一定。手机和电脑都可以通过浏览器打开官方网页版使用。是否下载 App，主要看你是否需要移动端通知、系统分享、语音等体验。

### ChatGPT网页版和 App 哪个更安全？

安全不只取决于形态，而取决于来源。网页版要核对 `chatgpt.com`，App 要从官方页面或应用商店核对发布方。来源不清的网页和安装包都应谨慎。

### 国内备用方案可以输入 OpenAI 官方账号吗？
