# ChatGPT 下载与安装教程

<div class="quick-answer">
  <strong>直接结论：</strong>下载 ChatGPT，优先从 `chatgpt.com/download` 进入，再根据设备选择 iOS、Android、Windows 或 macOS 渠道。不要从网盘、群文件或不明下载站安装。
</div>

<div class="recommend-box">
  <strong>国内可用方案：</strong>如果你不想安装官方客户端，只是想在国内环境体验多模型和图像能力，可以了解 <a href="https://gptcat.cc/" target="_blank" rel="noreferrer">GPTCat</a>。它适合把文字、图像、语音和视频能力放在同一环境里练习。
</div>

## 下载路径

| 设备 | 建议路径 |
| --- | --- |
| iPhone / iPad | 官方下载页跳转 App Store |
| Android | 官方下载页或 Google Play |
| Windows | 官方下载页或 Microsoft Store |
| macOS | 官方下载页或 OpenAI 帮助说明 |

## 安装前检查

1. 看发布者是否与官方信息一致。
2. 不安装破解包、增强版和网盘包。
3. 注意权限请求是否合理。
4. 登录前确认应用来源。

## FAQ

### 下载页打不开怎么办？

先确认 `chatgpt.com/download` 地址，再排查网络和浏览器。

### 第三方 AI App 都是假的吗？

不是。第三方工具可以存在，但不能冒充 OpenAI 官方 ChatGPT App。
