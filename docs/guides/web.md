## 使用网页版的基本流程

1. 打开 Chrome、Edge、Safari、Firefox 等现代浏览器。
2. 输入 `chatgpt.com`。
3. 确认页面和地址栏无异常。
4. 登录账号或按页面提示注册。
5. 在输入框中提出问题、上传允许的文件或开启页面提供的功能。

## 网页版安全提醒

网页登录最大的风险，是用户把账号密码输入到外观相似的假页面。判断时不要只看“聊天框像不像”，更要看地址栏、证书和跳转来源。

| 风险动作 | 更稳妥的做法 |
| --- | --- |
| 从短链接进入登录页 | 手动输入 `chatgpt.com` |
| 在教程站嵌入框中登录 | 跳转到官方页面后再登录 |
| 安装来历不明插件 | 先查官方说明和浏览器商店发布方 |
| 上传身份证、合同、源代码仓库 | 先脱敏，再确认是否必要 |

## FAQ

### ChatGPT 网页版是否等于 ChatGPT 官网？

网页版入口通常就是用户实际使用 ChatGPT 的页面，但“官网”还可能指 OpenAI 公司官网。使用时优先核对 `chatgpt.com`。

### 网页版打不开需要下载 App 吗？

不一定。先排查网络、浏览器、缓存和 DNS。下载 App 也应从官方下载页或应用商店进入。

### 网页版可以保存聊天记录吗？

是否保存、如何管理和能否删除，应以页面当前提供的账号设置和 OpenAI 政策说明为准。
