# ChatGPT 登录失败怎么办

<div class="quick-answer">
  <strong>直接结论：</strong>ChatGPT 登录失败时，先确认访问的是 `chatgpt.com`，再排查邮箱验证码、浏览器 Cookie、缓存、扩展和网络环境。不要把账号密码交给陌生客服代登录。

## 常见原因

| 现象 | 可能原因 | 处理建议 |
| --- | --- | --- |
| 验证码收不到 | 邮箱延迟或拦截 | 查垃圾箱，确认邮箱拼写 |
| 登录后跳出 | Cookie 或隐私设置 | 允许必要 Cookie |
| 页面一直转圈 | 网络或扩展冲突 | 换浏览器、关扩展 |
| 提示异常 | 网络环境或频繁尝试 | 暂停重复操作，稍后再试 |

## 安全提醒

验证码、登录邮件、恢复链接都可能让别人接管账号。任何要求你转发验证码的人，都不应轻信。

## FAQ

### 换浏览器有用吗？

有时有用。浏览器缓存、扩展和 Cookie 设置都会影响登录。

### 登录失败后能直接用镜像站吗？

可以阅读镜像站信息，但不建议在不明页面输入官方账号密码。
