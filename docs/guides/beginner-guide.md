# ChatGPT 怎么使用：新手从打开官网到开始提问

<div class="quick-answer">
  <strong>直接结论：</strong>新手使用 ChatGPT 的流程是：打开 `chatgpt.com`，确认地址无误，登录账号，在输入框写清任务和背景，再根据回答继续追问。
</div>

## 新手 5 步

1. 打开 `chatgpt.com`。
2. 登录账号或按页面提示注册。
3. 输入明确任务，例如“帮我把这段文字改得更简洁”。
4. 补充背景、语气、格式和限制。
5. 对回答继续追问，让结果更贴近需求。

## 提问模板

| 场景 | 可以这样问 |
| --- | --- |
| 写作 | 请把这段话改成更自然的中文，保留原意 |
| 学习 | 请用初学者能懂的方式解释这个概念 |
| 代码 | 这是报错信息，请帮我分析原因和排查步骤 |
| 总结 | 请用表格总结以下内容的要点 |

## FAQ

### ChatGPT 可以直接中文提问吗？

可以。中文用户不需要先把问题翻译成英文，但专业术语可以保留原文。

### 新手要不要安装 App？

不一定。网页版足够开始使用，App 更适合移动端和语音场景。
