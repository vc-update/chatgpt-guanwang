## 一、上传图片前先做安全检查

图片往往包含比文字更多的信息。无论使用官方页面还是第三方工具，上传前都先复制一份原图，并检查：

| 图片内容 | 风险 | 建议 |
| --- | --- | --- |
| 公开练习图或自制抽象图 | 较低 | 可以先用于测试提示词 |
| 普通个人生活照 | 中等 | 删除地址、门牌和可识别背景，确认肖像使用范围 |
| 客户照片或未成年人照片 | 较高 | 取得明确授权，非必要不要上传 |
| 合同、证件、账单和后台截图 | 高 | 不要直接上传，先改用脱敏局部或内部合规工具 |
| 未发布产品图、设计稿和源文件 | 高 | 评估商业机密和服务数据规则后再决定 |

尤其不要把 API Key、Cookie、验证码、密码、二维码或数据库截图当作“测试素材”。图片编辑工具不需要这些凭据。

## 二、GPT Images 2.5 官方网页版编辑步骤

功能名称和按钮位置可能随产品更新变化，下面是通用流程：

1. 手动打开 `https://chatgpt.com/`，确认最终域名和 HTTPS。
2. 登录后查看当前账号是否有图片生成、上传或编辑入口。
3. 上传已经脱敏的副本，先不要使用原始工作文件。
4. 第一条指令只说明编辑目标和必须保留的内容。
5. 查看结果后，再提出一个局部修改要求，不要一次改十个地方。
6. 下载前放大检查文字、边缘、人物身份、产品轮廓和背景反射。
7. 保存原图、每轮提示词和最终版本，方便回退和追溯。

如果官方页面没有显示相关功能，先查看帮助说明或稍后重试，不要安装所谓解锁插件，也不要在其他页面输入 OpenAI 登录凭据。

## 三、局部编辑指令怎么写

最实用的格式是：

```text
保留：明确列出不希望变化的主体、视角、颜色和光线。
修改：只说一个区域和一个主要动作。
不要：列出禁止新增、删除或改变的元素。
输出：说明比例、用途和是否需要留白。
```

### 示例一：整理房间，但不改变布局

```text
请基于上传的房间照片进行局部编辑。
保留：门、窗、床头柜、台灯、地板、拍摄角度和房间布局。
修改：只整理床面，把被子铺平、枕头摆整齐，并移除床上的杂物。
不要：新增家具，不改变窗户位置，不改变墙面颜色，不增加人物或文字。
输出：保持真实摄影质感和原图比例。
```

### 示例二：替换背景，但保留产品

```text
保留产品的外形、材质、颜色、接口、比例和原有阴影。
只修改背景：将背景替换为浅灰色摄影棚，并在产品右侧留出空白。
不要改变产品结构，不要新增Logo、型号、认证标志、价格或水印。
保持光线从左上方照射，输出一张适合电商详情页的1:1图片。
```

### 示例三：修改标题文字

```text
只修改图片左上角的大标题。
把“AI图片工具”改成“AI图片编辑入门”。
保留原来的字体方向、颜色、字号层级、背景和其他版式。
不要改动其他文字、数字、图标或联系方式。
如果无法保证中文准确，请保留标题区域为空，不要生成近似文字。
```

对于海报、信息图和商品详情页，文字越多，越容易出现错字和排版漂移。把“改字”拆成单个标题、单个日期或单个标签，通常比一次替换整张图更容易复核。

## 四、四类常见编辑任务

### 1. 删除杂物

写明物体的位置、大小和删除范围，同时说明主体不能变化。例如：“删除右下角桌面上的纸杯，保持桌面纹理、产品边缘和阴影自然。”

### 2. 替换背景

说明新背景的材质、颜色和光线方向，并要求保留主体轮廓。背景边缘最容易穿帮，生成后要放大检查头发、透明物体、产品边缘和地面接触处。

### 3. 调整比例和留白

先说用途，再说比例和留白位置。例如“改为 4:5 竖版，主体保持原大小，顶部增加干净留白用于后期标题”。不要只写“裁成适合手机的尺寸”。

### 4. 修正颜色和光线

每次只修改色温、亮度或主色中的一项。写“保持人物肤色和产品材质不变，只降低背景饱和度”，比写“整体更高级、更有氛围”更可执行。

## 五、编辑失败怎么排查

| 现象 | 可能原因 | 下一步 |
| --- | --- | --- |
| 主体被重新画了一遍 | 修改范围太宽，保留项不具体 | 增加主体轮廓、视角、材质和比例的保留要求 |
| 背景边缘不自然 | 原图遮挡复杂或光线不一致 | 缩小修改区域，补充光线和阴影方向 |
| 中文字变形或乱码 | 文字太小、行数太多 | 一次只改一个标题，或后期软件加字 |
| 人脸、手部或产品细节漂移 | 连续多轮变化累积 | 回到原图重新编辑，保留原始版本 |
| 生成了不需要的Logo或水印 | 没写禁止项，模型自行补全 | 明确“不要新增Logo、网址、水印和品牌标识” |
| 上传后没有编辑入口 | 账号、产品或当前阶段未开放 | 核对官方页面和帮助文档，不找破解或解锁链接 |

### 一个实用的回退方法

如果连续编辑三四轮后画面越来越偏，不要继续在最后一张图上补丁式修改。回到最初的原图，只保留已经验证有效的要求，再一次只改一个变量。这样比让错误细节层层累积更容易恢复。

## 七、发布前的图片验收清单

下载或发布前，逐项检查：

- 标题、日期、价格、地址和数字是否逐字正确；
- 人物身份、姿势、手部和肖像是否符合授权范围；
- 产品形状、型号、接口、材质和颜色是否被误改；
- Logo、商标、字体、地图和参考图是否有使用权限；
- 背景边缘、阴影、反射和透明物体是否自然；
- 是否误留了门牌、订单号、二维码或客户信息；
- 当前服务条款是否覆盖你的发布或商业使用场景。

## 常见问题

### GPT Images 2.5 能不能把原图完全保持不变，只改一个字？

不能保证像素级不变。可以通过“只修改某个区域”“保留主体和版式”“不要改变其他文字”等限制降低变化，但仍要与原图逐项对照。对正式海报，后期排版通常更稳。

### 上传图片前为什么要先脱敏？

照片和截图可能包含地址、姓名、二维码、客户资料、内部页面和未发布产品信息。脱敏可以减少不必要的数据暴露，也方便你控制后续版本。

### GPT Images 2.5 图片编辑失败，是模型坏了吗？

不一定。原图质量、遮挡、提示词范围、账号功能和当前服务状态都会影响结果。先缩小修改范围、明确保留项，并用低敏素材重复测试。

### SnakeGPT 是 GPT Images 2.5 官方入口吗？

不是。SnakeGPT 是独立第三方平台。是否提供某个图像模型和具体编辑能力，要以其当前菜单、公告和服务规则为准。

### 图片编辑结果可以直接交付客户吗？

不建议未经人工审核直接交付。至少要检查文字、事实、品牌、人物、版权和隐私；重要项目还应保留原图、提示词、版本和授权记录。
