搜索“ChatGPT个性化设置”的用户，通常想解决四件具体的事：让它每次都用中文回答、不必反复交代自己的职业背景、控制它记住多少、以及确认这些信息会被怎么使用。本文按设置面板的实际分组逐项说明，并给出可以直接粘贴的中文模板。

## 一、个性化设置在哪里

登录 [chatgpt.com](https://chatgpt.com/) 后，点右上角头像进入设置面板。常见分组是这样对应的：

| 你想做的事 | 通常在哪一组 | 影响范围 |
| --- | --- | --- |
| 固定回答语言、语气和身份背景 | 个性化 / 自定义指令 | 之后创建的新对话 |
| 改菜单和按钮的显示语言 | 通用 / 语言 | 只改界面，不改回答 |
| 查看或关闭模型记住的内容 | 个性化 / 记忆 | 后续对话的参考信息 |
| 控制数据是否用于改进模型 | 数据控制 | 账号级别 |
| 退出其他设备的登录 | 安全 / 已登录设备 | 账号级别 |

菜单名称和位置会随版本调整，网页端和 App 也可能不完全一致。找不到某一项时，用设置面板内的搜索框按关键词找，比自己逐层翻更快。

## 二、自定义指令怎么写

自定义指令通常分两个输入框：一个说明**你是谁**，一个说明**你希望它怎么回答**。填好保存后，之后每个新对话都会自动带上，不必重复交代。

### 有效写法和无效写法

关键区别是「可执行」还是「只是形容词」。模型无法从“专业一点”推断出你要的具体形式。

| 无效写法 | 为什么没用 | 改成 |
| --- | --- | --- |
| 回答专业一些 | 没有可判断的标准 | 先给结论，再列 3 条依据，每条注明适用前提 |
| 不要太长 | 长短无量化 | 正文不超过 300 字，超出改为分点 |
| 用中文 | 未区分场景 | 始终用简体中文回答，技术术语保留英文原词并首次出现时加中文解释 |
| 要准确 | 无法验证 | 不确定的地方标注“需核实”，不要用推测填补 |
| 像专家一样思考 | 无具体行为 | 给出方案时同时说明它在什么情况下不适用 |

### 可直接套用的模板

关于你自己的部分：

```text
我在国内做市场运营，日常处理中文文案、活动方案和数据周报。
英文可读但不熟练，技术背景一般。
我需要能直接用的成稿，不需要教学式解释。
```

关于回答方式的部分：

```text
始终用简体中文回答，专业术语保留英文原词并在首次出现时加中文解释。
先给结论和可执行步骤，再补充理由。
正文控制在 300 字以内，需要展开时改为分点。
涉及数据、时间、价格和政策时，标注这是需要我自己核实的信息，不要用推测代替。
我给出的文案请直接改写并输出成稿，不要只说改进建议。
```

写完保存，然后**新建一个对话**测试。自定义指令通常不影响已经打开的旧对话，在旧对话里试会以为没生效。

### 不应该写进去的内容

自定义指令会随后续每个新对话一起发送，所以它不是备忘录。以下内容不要写：

- 身份证号、手机号、家庭住址、银行卡和账号密码；
- 客户名单、合同金额、未公开的项目代号和内部报价；
- API Key、Cookie、恢复代码；
- 需要保密的雇主信息和未发布产品细节。

写职业背景时用“在国内做市场运营”这类描述就够，不必写公司全名和具体项目。

## 三、语言设置：界面语言不等于回答语言

这是最常见的误解。设置里的语言选项通常只改**界面**——菜单、按钮、提示文字，不决定模型用什么语言回答。

| 现象 | 真正的原因 | 怎么处理 |
| --- | --- | --- |
| 菜单是中文，回答却是英文 | 界面语言已改，回答语言未指定 | 在自定义指令里写明“始终用简体中文回答” |
| 中文提问却回复英文 | 提问里含大段英文原文，模型跟随了主要语种 | 加一句“请用中文回答”，或在自定义指令里固定 |
| 回答出现繁体或港台用词 | 未指定简体和用词习惯 | 写“简体中文，使用中国大陆常见表述” |
| 代码注释是英文 | 未单独说明 | 写“代码注释用中文，变量名保持英文” |
| 语音回复语言不对 | 语音功能可能有独立语言设置 | 在语音相关设置里单独确认 |

想彻底固定，把语言要求写进自定义指令，而不是每次提问时重复交代。界面语言改成中文只是让你自己看菜单更方便。

## 四、记忆：和自定义指令的分工

记忆是模型从对话中自动积累的信息，自定义指令是你手动填的固定说明。两者独立：关掉记忆，自定义指令照常生效；清空记忆，也不会动到自定义指令。

简单判断该用哪个：**长期不变的信息写进自定义指令**（职业、语言偏好、输出格式），**临时或阶段性的信息交给记忆或直接在对话里说**（正在做的某个项目）。

记忆的查看、关闭、删除，以及它和聊天记录、临时聊天的区别，站内已有专门一篇写得更细：[ChatGPT记忆功能怎么关闭和删除：个性化设置、聊天记录与隐私指南](/safety/chatgpt-memory-manage-delete-privacy-guide-20260808)。需要动记忆开关时看那篇，本文不重复。

## 五、数据控制里的选项

数据控制通常包含几个作用完全不同的开关，值得分清：

| 选项 | 作用 | 关掉之后 |
| --- | --- | --- |
| 用于改进模型 | 对话是否可能被用于训练 | 通常仍可正常使用，历史记录不受影响 |
| 聊天记录 | 是否保存对话列表 | 关掉后新对话可能不再出现在侧边栏 |
| 记忆 | 是否自动积累信息 | 已有记忆需另外清除 |
| 共享链接 | 已生成的公开链接 | 需要逐条停止共享，删对话不等于失效 |
| 导出数据 | 打包下载账号数据 | 导出文件本身包含完整对话，注意存放位置 |

关掉「用于改进模型」不等于对话不再经过服务器，只是影响它是否进入训练用途。真正敏感的材料，正确做法是**不要提交**，而不是依赖某个开关。

共享链接这一项容易被忽略：删掉对话不一定让已经生成的公开链接失效。站内相关说明见[ChatGPT共享链接怎么查看、停止共享与保护聊天隐私](/official/chatgpt-shared-links-view-stop-sharing-privacy-20260730)。

## 六、共享设备和工作电脑

自定义指令里的内容，任何能打开这个账号的人都看得到。公司电脑、家庭共用电脑或临时借用的设备上，建议：

- 职业背景写到行业和岗位就停，不写公司名、客户名和项目代号；
- 不把日程、联系人和内部流程写进指令；
- 离开前退出登录，而不是只关标签页；
- 定期在安全设置里查看已登录设备，清掉不认识的会话。

浏览器保存密码、自动填充和 Cookie 带来的风险，站内另有一篇：[ChatGPT官网浏览器自动填充安全吗？保存密码、Cookie与共享设备保护](/safety/chatgpt-browser-password-autofill-cookie-safety-20260825)。

## 七、设置不生效怎么排查

| 现象 | 先检查 |
| --- | --- |
| 自定义指令保存了但没变化 | 是否在旧对话里测试，新建对话再试 |
| 保存按钮点了没反应 | 是否超出字数上限，或浏览器扩展拦截了请求 |
| 手机 App 和网页端不一致 | 退出重进让设置同步，确认是同一个账号 |
| 设置项整个消失 | 可能是版本差异或分批开放，等一段时间再看 |
| 回答风格时好时坏 | 指令过长或互相冲突，删减到 5 条以内更稳定 |
| 换浏览器后设置没了 | 确认登录的是同一账号，而不是新注册的另一个 |

指令不是越多越好。写十几条互相冲突的要求，实际效果通常比五条清晰要求差。建议先写三到五条，用几天，再按实际不满意的地方补。

## 八、第三方产品的设置要单独看

第三方中文平台常有名称相似的设置项，但账号体系、存储位置和数据规则都是各自独立的。名字叫「自定义指令」不代表实现方式和 OpenAI 官方相同。

在第三方产品里配置个性化时，判断标准和官方一样：这段文字会不会随每次请求发送、平台有没有说明保存多久、能不能自己删除。说明不清楚的，就只写公开、低敏的内容。

## 九、常见问题

### ChatGPT个性化设置在哪里？

登录后点右上角头像进设置面板，个性化、语言和数据控制通常分在不同分组。菜单名称随版本变化，用面板内搜索框找更快。

### 自定义指令和每次提问时说要求，有什么区别？

自定义指令保存后自动作用于后续新对话，单次要求只影响当轮。两者可叠加，冲突时通常以本轮明确指令为准。

### 设置了中文为什么还用英文回答？

界面语言只改菜单。要固定中文回答，得在自定义指令里写明。

### 自定义指令会被用于训练吗？

取决于账号的数据控制设置和所用产品的当前规则。敏感信息不要写进去，因为它会随每个新对话一起发送。

### 关闭记忆后个性化设置还生效吗？

通常仍生效。自定义指令是手填的固定说明，记忆是自动积累的信息，两者独立。

### 指令写多少条合适？

先写三到五条可执行的要求。条目过多且互相冲突时，实际效果反而下降。

### 共享电脑上要注意什么？

自定义指令里的姓名、职位、公司和项目信息对任何能打开账号的人可见。减少可识别信息，离开前退出登录。

### 个性化设置能导出吗？

自定义指令是纯文本，自己复制保存即可，不需要第三方迁移工具。
