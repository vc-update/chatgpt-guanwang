## 登录前 5 步

1. 手动输入 `https://chatgpt.com/`。
2. 确认地址栏没有拼写错误或陌生跳转。
3. 检查页面是否通过 HTTPS 加载。
4. 确认没有要求安装未知插件或证书。
5. 再输入邮箱、密码或验证码。

## App 下载教程

下载 ChatGPT App 时，不建议从网盘、论坛附件或陌生下载站安装。更稳妥的顺序是：

1. 打开 `chatgpt.com/download`。
2. 根据设备进入 App Store、Google Play、Microsoft Store 或官方桌面端页面。
3. 核对开发者、应用详情页和权限。
4. 安装后登录前再次确认页面来源。

## 国内使用时怎么处理

## FAQ

### ChatGPT 登录入口是不是 openai.com？

OpenAI 官网是 `openai.com`，ChatGPT 网页登录入口优先看 `chatgpt.com`。两者可能互相跳转，但登录前以最终地址栏为准。

### App 下载页打不开怎么办？

先排查网络和应用商店状态，不要直接下载陌生安装包。

### 可以在国内第三方平台输入 OpenAI 账号吗？

不建议。第三方平台应使用独立账号，不应索要 OpenAI 密码或验证码。
