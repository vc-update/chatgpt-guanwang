## 安装前检查

1. 看开发者和发布来源。
2. 看是否跳到官方商店页面。
3. 不安装压缩包、破解包和绿色版。
4. 安装后只在官方登录流程输入账号。

## FAQ

### 搜索结果里的“Windows 官方下载”都可信吗？

不一定。标题写官方下载不代表来源可信，最终仍看域名和应用商店页面。

### Microsoft Store 打不开怎么办？

先检查系统区域、网络和商店状态。不要因为商店打不开就改装不明安装包。
