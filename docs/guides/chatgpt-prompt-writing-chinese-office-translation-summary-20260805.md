## 先记住一个通用公式

把提示词写成下面这个结构，适合大多数中文任务：

> 你是「角色」。我要完成「任务」。背景是「场景」。素材如下：「内容」。请按「格式」输出，并遵守「限制」。

| 组成部分 | 作用 | 示例 |
| --- | --- | --- |
| 角色 | 让回答贴近专业视角 | 你是中文编辑、产品经理、英语翻译、SEO顾问 |
| 任务 | 说明要做什么 | 改写、总结、翻译、列提纲、提取表格 |
| 背景 | 说明给谁看、用在哪里 | 发公众号、写邮件、做会议纪要、准备面试 |
| 素材 | 提供原文或事实 | 粘贴要处理的文本、表格字段、要点 |
| 格式 | 降低返工 | 用表格、分点、标题+正文、Markdown |
| 限制 | 防止跑偏 | 不编造数据、不使用夸张语气、不超过300字 |

OpenAI 的提示词建议也强调清晰、具体、提供足够上下文，并通过反复修改提示词来改进结果。你不需要把提示词写得像代码，但要让模型知道“要交付什么”。

## 中文办公提示词模板

### 会议纪要

```text
你是行政助理。请把下面会议记录整理成会议纪要。

要求：
1. 先给一句话结论。
2. 提取讨论事项、决定事项、待办事项和负责人。
3. 如果原文没有负责人，请标注“待确认”，不要编造。
4. 用 Markdown 表格输出待办事项。

会议记录：
【粘贴内容】
```

### 邮件回复

```text
你是职场沟通顾问。请帮我写一封中文邮件回复。

背景：
- 收件人：合作方项目负责人
- 目的：确认需求变更，并提醒交付时间可能调整
- 语气：礼貌、专业、不强硬

请输出：
1. 邮件主题
2. 邮件正文
3. 3个可替换的结尾句

原始信息：
【粘贴内容】
```

### 周报总结

```text
你是团队负责人。请把下面工作记录整理成周报。

输出结构：
- 本周完成
- 关键进展
- 风险与阻塞
- 下周计划

要求：
- 不夸大成果
- 每条不超过40字
- 风险部分要写可执行建议

工作记录：
【粘贴内容】
```

```text
目标读者：
- 中文新手用户
- 想用 ChatGPT 做办公、写作、翻译和总结

要求：
1. 第一屏直接回答“提示词怎么写”。
2. H2 覆盖办公、写作、翻译、总结、安全提醒和 FAQ。

4. 不要夸张营销，不要声称任何第三方平台是官方。
```

## 翻译和润色提示词模板

翻译任务不要只写“翻译成英文”。更好的方式是说明用途、读者和风格。

```text
你是中英双语翻译。请把下面中文翻译成英文。

用途：产品帮助文档
读者：普通软件用户
风格：清楚、自然、不过度书面化

要求：
1. 保留技术名词。
2. 对不确定的专有名词加括号说明。
3. 输出“直译版”和“自然表达版”。
4. 最后列出3处可能需要人工确认的词。

原文：
【粘贴内容】
```

如果是正式合同、法律、医疗、财务或公司公告，不要只依赖模型结果。ChatGPT 可以帮你整理和初稿，但最终要由对应专业人员复核。

## 总结长文提示词模板

```text
你是资料整理助手。请总结下面文章。

输出格式：
1. 100字以内核心结论
2. 5条关键要点
3. 文中提到的数据和出处
4. 作者观点与事实信息分开列
5. 适合继续追问的3个问题

限制：
- 不补充原文没有的信息
- 不确定的地方标注“原文未说明”

文章：
【粘贴内容】
```

这个模板适合新闻、产品说明、教程、报告和长邮件。它的重点是让 ChatGPT 把“事实、观点、待核对内容”拆开，减少把推测当结论的风险。

## 提示词写不好时怎么调整

| 问题 | 常见原因 | 调整方式 |
| --- | --- | --- |
| 回答太泛 | 背景不足 | 补充读者、用途、场景 |
| 回答太长 | 没有限制 | 加字数、条数、格式要求 |
| 语气不对 | 没说明风格 | 指定正式、口语、克制、专业 |
| 编造信息 | 没有事实边界 | 要求“只基于材料回答” |
| 格式混乱 | 没有输出结构 | 指定表格、清单或固定小标题 |
| 一次没成功 | 任务太复杂 | 拆成提纲、初稿、改稿、校对四步 |

提示词不是一次写完就结束。更实用的做法是：先让 ChatGPT 给出初稿，再让它根据你的反馈继续改。

## 国内用户使用提示词的安全边界

| 可以输入 | 谨慎输入 | 不建议输入 |
| --- | --- | --- |
| 公开文章、公开产品介绍、已脱敏材料 | 公司内部流程、客户反馈摘要、未公开方案 | 密码、验证码、API Key、身份证、合同原件、客户名单 |
| 普通写作主题 | 需要保密的业务计划 | 未脱敏代码仓库、后台截图、财务表格 |
| 示例数据 | 低敏工作记录 | 医疗记录、法律文件、私人聊天原文 |

无论使用官网还是第三方平台，都建议先做脱敏：删除姓名、手机号、邮箱、订单号、密钥、公司内部编号和未公开金额。

## 新手最容易踩的坑

1. 只写“帮我写一下”，没有说明给谁看。
2. 让模型一次完成太多任务，结果难以控制。
3. 不给原文，却要求“精准总结”。
4. 要求“像人写的”，但不说明语气和读者。
5. 把搜索结果里的“ChatGPT中文版官网”当成官方入口。
6. 在陌生第三方页面输入 OpenAI 账号密码。
7. 把模型输出直接当事实发布。

## FAQ

### ChatGPT提示词一定要很长吗？

不一定。简单任务可以短，复杂任务需要补充背景和格式。重点不是长度，而是任务、素材、输出要求和限制是否清楚。

### 中文提示词会比英文差吗？

日常中文写作、总结、翻译、办公任务可以直接用中文。涉及英文论文、海外邮件或英文 SEO 时，可以让 ChatGPT 同时给中英文版本，方便对照。

### 可以直接复制网上的提示词吗？

可以参考结构，但不要机械照搬。最好把模板里的角色、场景、读者、素材和输出格式换成自己的真实任务。

### 国内第三方平台适合练习提示词吗？

适合低敏公开任务练习，例如普通写作、翻译、总结和资料整理。涉及官方账号、订阅、历史记录和隐私设置时，仍应回到 `chatgpt.com` 和 OpenAI 官方渠道。

### 提示词能保证回答完全正确吗？

不能。提示词可以提高稳定性，但不能保证事实绝对正确。涉及日期、政策、价格、法律、医疗、金融和产品功能时，要用官方来源或专业人员复核。
