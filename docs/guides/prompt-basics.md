# ChatGPT 提示词入门：中文用户怎么问更清楚

<div class="quick-answer">
  <strong>直接结论：</strong>好的提示词不需要复杂术语，只要说清楚“我要你做什么、背景是什么、输出成什么格式、有哪些限制”。回答不满意时，继续追问比重新开聊更有效。
</div>

## 提示词公式

```text
请你扮演/作为：……
任务是：……
背景信息：……
输出格式：……
限制条件：……
```

## 示例

| 模糊问法 | 更清楚的问法 |
| --- | --- |
| 帮我写文案 | 请帮我写一段 120 字中文介绍，语气专业，适合官网首页 |
| 解释一下 | 用初中生能懂的方式解释，并举 2 个例子 |
| 改代码 | 根据这段报错分析原因，给出排查步骤，不要直接重写全部代码 |

## FAQ

### 提示词越长越好吗？

不一定。清楚比长更重要。

### 回答不满意怎么办？

告诉它哪里不满意、想调整什么方向，再让它重写。
