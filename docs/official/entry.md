ChatGPT 打不开或登录异常，不等于“官网换地址了”。常见原因有网络环境、浏览器缓存、DNS、地区可用性、账号验证、扩展冲突和临时服务状态。

| 现象 | 先做什么 | 不建议做什么 |
| --- | --- | --- |
| 页面打不开或白屏 | 换浏览器、清缓存、开无痕窗口、关掉扩展 | 立刻在陌生镜像站输入账号 |
| 登录后循环跳转 | 清理该站点 Cookie，减少频繁切换设备 | 把验证码发给所谓客服 |
| 提示 Access Denied | 核对域名、稍后重试、检查网络环境 | 相信“唯一可用官网”的付费页 |
| 下载页打不开 | 从 openai.com 或应用商店核对 | 下载网盘里的安装包 |

## 常见错误与避坑清单

- 只看搜索结果标题就登录。标题写“官方”不代表域名是官方，务必手动输入 chatgpt.com。
- 把“中文版官网”当成 OpenAI 官方。官方支持中文对话，但中文版页面不一定是官方服务。
- 把验证码或恢复码发给“客服”。官方登录流程不会让你把验证码转发给任何人。
- 从群文件、网盘、弹窗广告下载“ChatGPT 客户端”。这类安装包被仿冒和捆绑的风险很高。
- 在陌生镜像页反复输入官方账号密码。一旦页面是仿冒的，账号可能立即泄露。
- 因为一次打不开就换到“唯一可用官网”付费页。先排查本地网络和浏览器，再判断。
- 在第三方平台上传敏感资料。合同、客户信息、密钥、后台截图和未脱敏代码不要上传。
