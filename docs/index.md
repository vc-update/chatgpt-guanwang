## 常见问题

### ChatGPT 官网入口是哪个？

ChatGPT 网页入口优先以 `https://chatgpt.com/` 为准。OpenAI 公司官网以 `https://openai.com/` 为准。两者可能互相跳转，但登录前应以浏览器地址栏最终显示的域名为准。

### 本站是 OpenAI 或 ChatGPT 官方网站吗？

不是。本站是面向中文用户的非官方独立整理，只做入口识别、安全访问和风险提醒，不代表 OpenAI 或 ChatGPT 发布官方公告。

### 搜索结果里的“ChatGPT 中文版”可以直接登录吗？

不建议直接把账号密码输入到陌生页面。先判断它是教程站、镜像站、聚合工具，还是仿冒登录页。如果不能清楚说明服务主体、隐私处理和登录方式，就应谨慎。

### ChatGPT 打不开就是官网换了吗？

不一定。打不开可能来自网络、DNS、浏览器缓存、地区可用性、账号风控或临时服务状态。先核对 `chatgpt.com` 和 `openai.com`，再排查本地环境。
